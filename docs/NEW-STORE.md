# Adding a new Outlet Mall store

Use the kit at **`units/_store-template/`**.

1. Read `units/_store-template/STORE_BRIEF.md` and fill it.
2. Copy the folder to `units/<slug>/` and rename `store.css` / `store.js`.
3. Add photos under `assets/` (required list is in the brief).
4. Register the door in `data/stores.json`.
5. Study finished rooms: `fish-store`, `comic-shop` (and Arcade for heavy media).

Live mall: https://outlet-mall.vercel.app  
Repo: https://github.com/ozone503-maker/outlet-mall
