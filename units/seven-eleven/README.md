# 7-Eleven (mall unit)

Fictional in-universe collab: the convenience store where Slurpee flavors meet
Fruity Puppy. Kept playful and obviously fictional. Display/lookbook only; the
only outbound path is fruitypuppy.com.

## Files
- `index.html`: approach, lede, flavor lab, counter, rollers, 3am walk, outbound
- `seven-eleven.css`: dark mall theme, orange/green accent
- `seven-eleven.js`: tap a photo to look closer
- `assets/`: 6 images (copies, originals untouched)
