# Shoe Station (mall unit)

A straightforward mall shoe store in the mall's deadpan voice. No real brand
partner, so the outbound link goes to fruitypuppy.com with an honest label.
Display/lookbook only.

## Files
- `index.html`: approach, lede, fitting, floor, house rules, hallway, outbound
- `shoe-store.css`: dark mall theme, amber accent
- `shoe-store.js`: tap a photo to look closer
- `assets/`: 4 images (copies, originals untouched)
