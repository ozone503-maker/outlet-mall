# BroBots Space Factory (mall unit)

Jessie's web-design brand, as a mall showroom. Display/lookbook only; the only
transaction path is the outbound link to the real site.

## Files
- `index.html`: showroom page (approach, lede, roster, workbench, clientele, outbound)
- `brobots-retail.css`: dark mall theme, blue accent
- `brobots-retail.js`: tap a photo to look closer
- `assets/`: 6 images (copies, originals untouched)
