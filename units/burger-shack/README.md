# burger-shack

Image-first unit. Layout keys off aspect ratio: wide viewports (desktop and a
phone held sideways) get the full-bleed treatment, portrait gets a single column.

## Files
- `index.html` — the room
- `burger-shack.css` — unit styling, inherits tokens from `/outletmall/mall.css`
- `burger-shack.js` — behaviour
- `assets/` — 4 video, 0 audio, 10 image

## Swapping a shot
Drop a replacement into `assets/` under the same filename. No code change.
